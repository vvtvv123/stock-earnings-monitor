# Stock Earnings Monitor

## Data contract
This project is a data system for US stock earnings monitoring.
The agent's job is to maintain and advance the data, not the code framework.

- `data/alerts.jsonl` — emitted alert records for Telegram delivery

## Authoritative data sources
### Calendar / next earnings date and exact report time
- Primary: NASDAQ public API
  - Endpoint: `https://api.nasdaq.com/api/calendar/earnings?date=YYYY-MM-DD`
  - Fields: `symbol`, `report_date`, `time`, `timeZone`, `epsActual`, `revenueActual`, `epsEstimate`, `revenueEstimate`
- Fallback: `yfinance.Ticker.earnings_dates` when installed

### Actual earnings numbers
- Primary: NASDAQ earnings calendar rows when the report has released actuals
- Secondary: SEC EDGAR filings
  - Use `https://www.sec.gov/cgi-bin/browse-edgar?action=getcompany&CIK={ticker}&type=8-K&dateb=&owner=include&count=40`
  - Find the most recent 8-K filing for earnings and parse exhibit/attachment text for EPS, revenue, period, guidance if present
- Optional: Yahoo Finance / `yfinance` historical tables and `quarterly_financials` when installed

## Data pipelines
### 1. Exact-datetime earnings workflow
Given date `X` and time `Y`, query NASDAQ calendar for date `X` and find tickers reporting at exact time `Y` within `window_minutes`.

### 2. Real-time scoring
Fetch live reported data for only those reporting tickers.
Score against alert criteria:
- EPS actual exceeds EPS estimate by >= 5%
- Revenue actual exceeds revenue estimate by >= 1%
Emit alerts to `data/alerts.jsonl`.

## Invariant
All work must be executable with plain `python src/<name>.py`.
No new dependency on FastAPI or other apps unless requested.

## Conventions
- Use `requirements.txt` for dependencies only.
- Use `data/` for JSONL outputs.
- Do not hardcode credentials. Read from env or `config.yaml`.
- Telegram sending is the Hermes gateway usage here.
- Keep changes minimal and focused.

## Suggested run order
1. `python src/fetcher.py --at --date YYYY-MM-DD --time HH:MM`
2. `python src/watcher.py --once --lookahead-days N`
3. `python src/fetcher.py --schedule`
4. `python src/scorer.py --emit-alerts`
5. `python src/alert_telegram.py`
